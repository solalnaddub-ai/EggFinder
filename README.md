# EggFinder

EggFinder is a Roblox egg discovery project.

## Features
- Minimum gain: 10B/s
- Sort eggs by gain per second
- Display all qualifying eggs
- Exclude full servers
- Refresh display every second

## Files
- `EggFinder.lua` — User interface
- `ServerScanner.lua` — Public server discovery
- `EggDetector.lua` — Egg filtering and sorting
- `Config.lua` — Project settings

## Important
EggFinder only works with egg data from an authorized source.
It does not access private game data or bypass Roblox protections.
